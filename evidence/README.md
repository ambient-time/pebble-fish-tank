# Fish Count native evidence

The PNGs show the face at native resolution on the named Pebble emulator.
Each platform report ties its screenshots and logs to the installed PBW's
SHA-256. The validation summary lists the six targets.

The standard views cover 10:08, 12:00, 03:15, 18:30, and 11:24. Rollover views
show the approach to noon and midnight, followed by the next hour. The cadence
check compares idle frame counts, a tap burst, and the return to idle.

Color and monochrome inspection covers twelve-fish visibility,
minute kelp, separated nuggets, and the rectangular or circular aquarium frame.
The fixed local daylight tint and native motion differ from the location-aware
web source as described in the main README.

These captures establish emulator behavior. Battery life, wrist-tap behavior,
and daylight readability on physical watches remain unmeasured.
